# @sumirea/extension

The **browser-extension surface** for Sumirea.

> [!IMPORTANT]
> The extension is **not** the product. It is one delivery surface among several
> for the workflow layer that lives in `packages/`. It is deliberately thin: it
> wires `@sumirea/sdk` to `@sumirea/ui` and the browser's extension APIs, and
> contains no workflow logic.

**Depends on:** `@sumirea/sdk`, `@sumirea/ui` · **Status:** scaffold only, no
manifest or wiring yet.
