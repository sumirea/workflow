# @sumirea/ui

**Shared presentational components.**

Surface-agnostic, reusable UI building blocks shared by the visual surfaces —
the browser extension, the docs site, and any future web app. Components here
are **presentational only**: they render state and emit intent; they hold no
workflow logic and make no decisions that belong in `core`.

**Depends on:** `@sumirea/schema` (types only) · **Status:** scaffold only.
