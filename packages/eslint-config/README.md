# @sumirea/eslint-config

Internal, shared ESLint flat-config preset for the Sumirea monorepo. Not
published.

A natural home for **architectural lint rules** — e.g. enforcing the
`apps → sdk → core → schema` import direction described in
[`ARCHITECTURE.md`](../../ARCHITECTURE.md) — so boundary violations fail CI
rather than relying on review. Rules are not defined yet.
